## Qué se hizo

### `rewards_roadmap_screen.dart`

**Función top-level `filterAndSortPremios(premios, levelFilter)`**
- No lleva `_` para poder importarla directamente en tests
- Filtra por `nivelMinimo == levelFilter` **o** `nivelMinimo == null` (premios sin nivel
  mínimo siempre aparecen, independientemente del filtro)
- Ordena ascendente por `costoPuntos` con cascade `..sort(...)` sobre la expresión
  ternaria (necesario para satisfacer `cascade_invocations`)

**`RewardsRoadmapScreen` (`ConsumerStatefulWidget`)**
- Estado local: `OperatorLevel? _levelFilter` (null = Todos)
- `targetIndex` — `milestones.indexWhere((p) => available < p.costoPuntos)` — primer
  hito no alcanzado; se pasa al `RoadmapMilestone` correspondiente como `isTarget: true`
- Lista construida con `ListView.builder` + animación escalonada
  `.fadeIn(300ms, delay: 60ms*i).slideX(begin: -0.04)`

**`_LevelFilterBar`**
- `SingleChildScrollView` horizontal con chips: "Todos" + `OperatorLevel.values`
- Retap sobre el nivel activo lo desactiva (toggle): `onSelected: (_) => onChanged(selected == level ? null : level)`

**`_EmptyRoadmap`** — ícono mapa + mensaje cuando no hay premios en el nivel seleccionado

### `roadmap_milestone.dart`

**`RoadmapMilestone` (`StatelessWidget`)**
- Parámetros: `premio`, `availablePoints`, `operatorLevel`, `isLast`, `isTarget`
- `reached = availablePoints >= premio.costoPuntos`
- `canCanje = reached && (nivelMinimo == null || operatorLevel.index >= nivelMinimo.index)`
- Layout: `Row(crossAxisAlignment: start)` — track column (40px) + gap (16px) + card (Expanded)
- `_openSheet` con `unawaited(showModalBottomSheet(...))` → abre `CanjeSheet`

**`_TrackColumn`**
- Nodo `_NodeCircle` de 40×40
- Línea conectora de 2×72px debajo del nodo (oculta si `isLast`), con `borderRadius: 1`
- Color: tipo color si `reached`, `Colors.grey.shade300` si pendiente

**`_NodeCircle`**
- `reached` → contenedor filled con color + sombra `withAlpha(60)`
- `isTarget` → outlined + `.animate(onPlay: c.repeat(reverse: true)).scale(0.88→1.12, 900ms, easeInOut)` — pulsa continuamente
- Pending → outlined sin animación

**`_MilestoneCard`**
- Nombre + `_LevelChip` (si `nivelMinimo != null`)
- Tipo displayName en gris
- `LinearProgressIndicator` con `valueColor: AlwaysStoppedAnimation<Color>(color)`
- "¡Alcanzado!" verde / "Faltan X pts" gris
- `${premio.costoPuntos} pts` con ícono `stars_rounded` en color del tipo
- `FilledButton.tonal('Canjear')` visible solo si `canCanje`

**`_LevelChip`** — chip gris redondeado con el `displayName` del nivel mínimo

**Colores por `PremioTipo`:**

## Problema encontrado

| Problema | Solución |
|---|---|
| `cascade_invocations`: `result` declarado, luego `result.sort(...)` en línea aparte | Reescrito como `(... ? ... : ...)..sort(...)` — cascade sobre la expresión completa |
