# Sesión 2026-05-12 — Fase 4: Home Dinámico + Animaciones + Limpieza de Lint

## Qué se hizo

### HomeState — lógica de negocio del home (home_provider.dart)

- `HomeState` como `sealed class` con tres subtipos:
  - `HomeStateActiveTrip(Trip trip)` — operador tiene un viaje en curso
  - `HomeStateWelcomeBack(List<Trip> recentTrips)` — regresa después de ≥1 día sin abrir la app
  - `HomeStateDashboard(List<Trip> recentTrips)` — vista normal con métricas del mes
- `homeStateProvider` (`StreamProvider<HomeState>`): combina `authStateProvider`, `tripsProvider` y `sharedPreferencesProvider` para determinar cuál vista mostrar
- `updateHomLastSeen(WidgetRef)` — persiste `DateTime.now()` en SharedPreferences; llamada desde `initState` del HomeScreen
- Helpers privados: `_activeTrip()`, `_isWelcomeBack()`, `_monthlyKm()`, `_monthlyPoints()`

### HomeScreen — tres vistas animadas (home_screen.dart)

- `ConsumerStatefulWidget`; `initState` llama `updateHomLastSeen(ref)` con `unawaited`
- Switch en `homeStateProvider` despacha a tres vistas:
  - `_ActiveTripView` — muestra `ActiveTripCard` centrado con animación fade+slide
  - `_WelcomeBackView` — saludo de regreso + últimos 3 viajes como `TripCard` con `onTap → context.push('/trips/:id')`
  - `_DashboardView` — `_MonthStatsRow` (KM + puntos del mes), `_StreakCard` (icono fuego, días de racha), `_PointsBalanceCard` (gradiente ámbar, puntos disponibles), últimos viajes
- `_PointsBadge` interno con chip de nivel del perfil
- Todas las secciones animadas con `flutter_animate`: `.fadeIn(duration: 400.ms).slideY(begin: 0.15, end: 0)` con `delay` escalonado por sección
- `_NoTripPlaceholder` cuando no hay viajes históricos

### ActiveTripCard — card de viaje activo (active_trip_card.dart)

- `ConsumerWidget` que observa `tripDetailProvider(trip.id)` para obtener puntos GPS del mapa miniatura
- Punto de estado pulsante (`_PulsingDot`) con `flutter_animate` en loop: `.animate(onPlay: (c) => c.repeat(reverse: true)).scale(begin: Offset(0.8, 0.8), end: Offset(1.2, 1.2))`
- Mapa miniatura via `TripMapView(points: detail.gpsPoints, height: 160)` — solo se muestra si hay puntos GPS (`whenOrNull` para evitar estado de carga)
- `_StatsRow` con tres métricas: tiempo transcurrido desde `fechaInicio`, KM recorridos, rendimiento actual
- `_elapsed(DateTime start)` — helper estático que formatea la duración en `HH:MM`

## Problemas encontrados y soluciones

| Problema | Solución |
|---|---|
| `discarded_futures` en `updateHomLastSeen` — `setInt` devuelve `Future<bool>` | `unawaited(...)` tras importar `dart:async` |
| `prefer_int_literals` en `fold(0.0, ...)` — literal `0.0` activa el lint | `fold<double>(0, ...)` con tipo genérico explícito para que el fold siga siendo `double` |
| `use_super_parameters` disparado por DAOs de Drift | `use_super_parameters: false` en `analysis_options.yaml`; documentado en CLAUDE.md Gotcha #9 |
| `document_ignores` exige comentario en la línea ANTERIOR al `// ignore:` | Añadir línea de comentario explicativo antes de cada directiva `// ignore:` |
| `GpsPoint` y `SecurityAlert` tenían parámetros `required` después de opcionales | Reordenamiento en la factory Freezed; como son named params, los callsites no cambian |
| `lines_longer_than_80_chars` en `_formatAntiguedad` (ternary anidado) | Extraída variable `yearStr`; convertido a `if (m == 0) return yearStr` |
| `final subtitle = (alert.valorMedido != null && alert.umbralPermitido != null)` — 81 chars | Partido en dos líneas con el `&&` al final de la primera |
