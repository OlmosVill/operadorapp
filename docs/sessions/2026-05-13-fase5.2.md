### Edge Function — `supabase/functions/canjear-premio/index.ts`

Validaciones en orden (con code de error HTTP semántico):
1. JWT → `401`
2. Parámetros body → `400`
3. Premio activo → `404`
4. Stock > 0 → `409`
5. Saldo del operador en `puntos_operador` → `402`
6. Nivel del operador vs `nivel_minimo` → `403`

Crea `premios_canjeados` con `estado='solicitado'`. Decrementa stock si es limitado.
La deducción real de puntos ocurre después vía trigger `trg_canje_aprobado` cuando RH aprueba.

## Problemas encontrados y soluciones

| Problema | Fase | Solución |
|---|---|---|
| `gt()` undefined en `PostgrestTransformBuilder` — `order()` encadenado antes del `gt()` condicional | 5.1 | Mover `order()` al final, después del bloque `if (since != null)` |
| `inference_failure_on_instance_creation` en `points_repository_impl.dart` | 5.1 | Tipos genéricos explícitos: `Left<AppError, List<PointMovement>>(...)` |
| `only_throw_errors` en `points_provider.dart` — `AppError` no es `Exception` | 5.1 | `throw Exception(err.toString())` |
| `Stream.handleError` no emite datos — el handler es `void` | 5.1 | Reescrito con `async*` / `await for` + try-catch; documentado como Gotcha #14 |
| `emits(Right([]))` falla — dos `[]` distintos no son iguales por referencia | 5.1 | `isA<Right<L,R>>().having((r) => r.value, 'value', isEmpty)` |
| `sort_pub_dependencies` — SDK deps (`flutter:`, `flutter_test:`, etc.) fuera de orden | 5.1 | Mezcladas alfabéticamente con el resto de dependencias en `pubspec.yaml` |
| `'Tarjeta $500'` — `$5` es interpolación inválida (dígito, no identificador) | 5.2 | Raw string `r'Tarjeta $500'` en tests |
| `discarded_futures` en `_openSheet` (showModalBottomSheet no awaiteado) | 5.2 | `unawaited(showModalBottomSheet(...))` + `import 'dart:async'` |
| `always_put_required_named_parameters_first` en `PremioCard` y `CanjeSheet` | 5.2 | `required this.premio` movido antes de `super.key` |
| `avoid_redundant_argument_values`: `pinned: true` en `SliverAppBar.medium` | 5.2 | Removido (`true` es el default del constructor `.medium`) |
| `prefer_const_constructors` en tests: `Left(...)` y `Right([])` | 5.2 | `const Left<AppError, List<Premio>>(UnexpectedError())` y `const Right<AppError, List<Premio>>([])` |
| Dividers de 81 chars en `rewards_screen.dart` | 5.2 | Removido 1 `─` del final de cada divider |
