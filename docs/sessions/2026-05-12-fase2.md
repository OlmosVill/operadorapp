## Problemas encontrados y soluciones

| Problema | Solución |
|---|---|
| `tableName` como columna Drift | Renombrar a `tableKey` |
| `super.db` lint `matching_super_parameters` | Usar `Constructor(AppDatabase db) : super(db)` |
| `StreamProvider<T>` con `Stream<Either<AppError,T>>` | Agregar `.map((r) => r.fold(...))` |
| `sqlite3_flutter_libs: ^0.6.0+eol` no empaqueta el `.so` | Cambiar a `^0.5.0` |
| `applyWorkaroundToOpenSqlite3OnOldAndroidVersions` no encontrado | Consecuencia del punto anterior; versión `+eol` no exporta la función |
| `LocaleDataException` en perfil | Agregar `await initializeDateFormatting('es_MX')` en `main()` |
